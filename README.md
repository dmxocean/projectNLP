# Project: Sequence Tagging for Negation and Uncertainty Detection

This project tasks a group of 4 students with implementing three **Sequence Tagging techniques** to detect **Negation** and **Uncertainty** in text:

- **Rule-Based Algorithm**  
  - Utilizes basic text processing (e.g., NegEx with negation triggers, regex).
  
- **Machine Learning System**  
  - Employs non-deep learning models with text features (e.g., PoS tagging, word embeddings).
  
- **Deep Learning System (Optional)**  
  - Bonus task using advanced models like LSTM/GRU or Transformers.


## Key Steps

1. **Literature Review**  
   - Research prior work (e.g., Mahany et al., 2022) to inform your approach.
   
2. **Method Design**  
   - Adapt existing methods or innovate based on findings.
   
3. **Data Pre-processing**  
   - Handle redacted, multilingual (Catalan/Spanish), and noisy text.
   
4. **Implementation**  
   - Develop and test all three systems.
   
5. **Methodology**  
   - Follow the scientific method: form hypotheses, conduct experiments, measure with metrics, and draw data-driven conclusions.
